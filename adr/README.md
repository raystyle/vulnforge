## 单文件格式

```markdown
# ADR-NNN | 标题

- 日期：YYYY-MM-DD
- 状态：提案中 / 实施中 / 已完成 / 已废弃

## 需求

用户要什么（原话或确认措辞），含子需求拆分

## 进度状态

各子需求当前状态 + 剩余待办（表格）

## 最终产物

交付资产清单：路径 + 一句话（表格）

## 是否满足需求

判定（满足/部分/不满足）+ 证据（验证方式、用户确认）
```

## 维护规则

- 新需求 → 新文件，序号递增，不重排不删除
- 不写过程叙事（研究经过、讨论历史不进 ADR；需要时留 git 历史或 memory）
- 进度变化只改"进度状态"节；产物交付补"最终产物"节；验证完成更新"是否满足需求"节并同步本索引
- 四节齐且满足判定成立 → 状态"已完成"
- 决策固化进 docs/ 后，memory 只留指针
