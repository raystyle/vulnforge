# ADR / docs 管理规则

## 目录分工

- `adr/` — 仓根独立目录：需求跟踪记录（每条一个单文件 + README 索引）
- `docs/` — 产品文档：项目功能特性、部署安装等面向产品的材料（暂空，待产品成型时建）

## ADR 纪律

- 每条 ADR 必须由用户决定后才能写入 `adr/`；Claude 只起草候选内容供用户确认，未经确认不写入文件
- ADR 是需求跟踪记录：需求 / 进度状态 / 最终产物 / 是否满足需求四节，不写过程叙事
- 用户粘贴的参考资料不作为 ADR 条目，只作背景记录或沉淀至 CLAUDE.md
- 状态取值：提案中 / 实施中 / 已完成 / 已废弃
- 固化进 adr/ 后，memory 只留指针
- 文档用中文

## docs 纪律

- 产品文档随功能成型逐步建立；操作过程知识归 skills，不进 docs
